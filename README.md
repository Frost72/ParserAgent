Парсер для информационно-аналитической системы оценки инвестиционной привлекательности предприятий общественного питания предназначен для автоматизированного сбора данных из открытых источников. Он обеспечивает потоковую и пакетную загрузку информации о заведениях общественного питания (название, адрес, тип, ценовой сегмент, рейтинг, количество отзывов, средний чек), а также текстов отзывов посетителей с оценками. Дополнительно парсер собирает данные об инфраструктуре (торговые центры, учебные заведения, бизнес-центры, парки, стадионы), транспортной доступности (остановки, парковки), демографические и экономические показатели по районам. Все данные проходят очистку, нормализацию, дедупликацию и геокодирование адресов, после чего агрегируются по административным районам и радиусам для последующего многокритериального анализа и расчёта интегрального показателя устойчивости.
